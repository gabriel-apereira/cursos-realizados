# 📊 Curso de Análise de Dados com Python

Bem-vindo(a) ao repositório oficial do curso **Análise de Dados com Python** oferecido por [dataengineer.help](https://dataengineerhelp.odoo.com/slides/analise-de-dados-com-python-13).  
Este curso é uma jornada completa para quem deseja dominar as principais bibliotecas utilizadas no **processamento, validação e visualização de dados** com Python.

---

## 🎯 Objetivos do Curso
- Ensinar manipulação de arrays e cálculos numéricos com **NumPy**.
- Demonstrar como estruturar e transformar dados com **Pandas**.
- Validar e garantir a qualidade dos dados com **Pandera**.
- Criar gráficos impactantes e explorar padrões com **Seaborn**.
- Aprofundar técnicas avançadas de otimização e manipulação de arrays com **NumPy Avançado**.

---

## 📚 Conteúdo Programático
1. **NumPy Básico**
   - Arrays e operações matemáticas
   - Cálculos numéricos eficientes
2. **Pandas**
   - Estruturação de datasets
   - Transformações práticas
3. **Pandera**
   - Validação de dados
   - Garantia de qualidade e consistência
4. **Seaborn**
   - Visualização de dados
   - Gráficos e exploração de tendências
5. **NumPy Avançado**
   - Técnicas de otimização
   - Manipulação avançada de arrays

---
